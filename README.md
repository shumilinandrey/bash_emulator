# Эмулятор терминала

## 1. Общее описание
Проект представляет собой графический эмулятор командной строки UNIX-подобной ОС, реализованный на Python. В рамках текущих этапов разработки реализовано:
* Этап 1 (REPL)
  * Диалог с пользователем в графическом окне.
  * Динамическое формирование строки приглашения и заголовка окна на базе параметров текущего пользователя ОС.
  * Команды-заглушки `ls` и `cd`, команда завершения `exit`.
  * Масштабирование шрифта с клавиатуры без искажения исходных размеров окна.
  * Защита пользовательского приглашения от случайного стирания клавишей Backspace.
* Этап 2 (Конфигурация)
  * Поддержка параметров командной строки: Путь к VFS и путь к стартовому скрипту.
  * Отладочный вывод всех полученных параметров конфигурации при старте эмулятора.
  * Исполнение стартового скрипта с имитацией ввода/вывода.

## 2. Описание всех функций и настроек

### Описание функций логики команд
* `ls(args: list[str]) -> str` - реализует логику команды `ls` (на данном этапе разработки в виде заглушки).
* `cd(args: list[str]) -> str` - реализует логику команды `cd` (на данном этапе разработки в виде заглушки).
* `exit_app() -> None` - закрывает окно эмулятора терминала и завершает процесс.

### Служебные функции
* `cout(text: str) -> None` - осуществляет вывод переданной строки в эмулятор консоли посредством её вставки в буфер виджета `tk.Text`, прокручивает область просмотра вниз.
* `parse_arguments(args: list[str] | None = None) -> argparse.Namespace` - осуществляет разбор параметров командной строки.
* `process_command(command: str) -> None` - разбирает переданную строку на имя команды и список аргументов, вызывает соответствующий обработчик.
* `process_script(script_path: str) -> None` - выполняет построчное чтение и исполнение команд из стартового скрипта с отображением ввода/вывода на экране.
* `enter(event: tk.Event) -> str` - Обработка нажатия клавиши Enter. 
* `backspace(event: tk.Event) -> str` - Обработка нажатия клавиши BackSpace: предотвращение удаления пользовательского приглашения.
* `zoom_in(event: tk.Event) -> str` - Обработка клавосочетания Ctrl +: увеличивает текущий размер шрифта на `FONT_SCALING_STEP`.
* `zoom_out(event: tk.Event) -> str` - Обработка клавосочетания Ctrl -: уменьшает текущий размер шрифта на `FONT_SCALING_STEP`.
* `is_root() -> bool` - Проверка прав суперпользователя.
* `main() -> None` - Запуск приложения, отрисовка окна с помощью Tkinter.
### Константы
* `ROOT_UID = 0` - числовой идентификатор суперпользователя.
* `DEFAULT_FONT_SIZE = 14` - размер шрифта по умолчанию.
* `FONT_SCALING_STEP = 2` - шаг изменения размера шрифта.
* `MIN_FONT_SIZE = 6` - нижняя граница размера шрифта.
* `MAX_FONT_SIZE = 40` - верхняя граница размера шрифта.
* `WINDOW_HEIGHT = 600` - высота окна в пикселях.
* `WINDOW_WIDTH = 800` - ширина окна в пикселях.
* `CURRENT_DIRECTORY = '~'` - текущая директория(её изменение на данном этапе разработки не предусмотрено).

## 3. Описание команд для сборки проекта и запуска тестов.

### Запуск программы
Для работы программы требуется установить необходимые библиотеки:
```bash
pip install -r requirements.txt
```

Запустить программу можно через пусковой скрипт:
```bash
chmod +x run.sh
./run.sh
```

Запуск через интерпретатор Python с пользовательскими параметрами:
```bash
python3 src/main.py -vfs vfs.json -s script.txt
```

### Запуск тестов
Для прогона набора тестов используется pytest:
```bash
python3 -m pytest -v tests/
```

Для проверки поддерживаемых конфигураций командной строки в папке tests подготовлены скрипты запуска под Windows.

## 4. Примеры использования

При запуске -vfs vfs.json -s script.txt в начале окна терминала отображается блок отладки:
```bash
[*] Запуск эмулятора терминала...
[+] VFS path   : vfs.json
[+] Script path: script.txt
```

Далее формируется и выводится на экран пользовательское приглашение, например `andrew@debian:~$`. 

Если указан какой-либо стартовый скрипт, то команды в нём последовательно выполнятся.

### Использование команды ls или cd
Логика команд на данном этапе разработки идентична, поэтому целесообразно объединить примеры их использования.
Ввод:
```bash
ls -l
```
Вывод:
```bash
ls -l
```

### Использование неизвестной команды
Если эмулятор терминала получит на вход неизвестную команду - он выведет сообщение об ошибке.
Ввод:
```bash
touch main.py
```

Вывод:
```bash
Неизвестная команда touch
```

### Выход из эмулятора терминала
Ввод:
```bash
exit
```
Программа завершит свою работу. Графическое окно закроется, программа получит код завершения 0.
